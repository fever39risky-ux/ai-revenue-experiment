---
title: "APIキーをコードに書かない：スクリプトプロパティと利用上限"
---

多くの入門記事では、コードの先頭に `const API_KEY = 'sk-...'` と書きます。動きますが、スプレッドシートを誰かと共有したり、コードをコピーして人に渡したりした瞬間に、キーも一緒に渡ります。最初から**スクリプトプロパティ**に置きましょう。

## 1. キーを保存する

Apps Scriptエディタの左メニュー「⚙ プロジェクトの設定」→ 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」で、次のように登録します。

| プロパティ | 値 |
|---|---|
| `OPENAI_API_KEY` | `sk-` で始まるキー |

コードからは次のように読みます。

```javascript
function getApiKey_() {
  const key = PropertiesService.getScriptProperties().getProperty('OPENAI_API_KEY');
  if (!key || key.indexOf('sk-') !== 0) {
    throw new Error('スクリプトプロパティ OPENAI_API_KEY が未設定です（プロジェクトの設定 → スクリプト プロパティ）。');
  }
  return key;
}
```

スクリプトプロパティは、スプレッドシートの閲覧者には見えません。ただし**スクリプトを編集できる人には見えます**。編集権限を渡す相手は絞ってください。

## 2. 使いすぎを防ぐ

自動化で一番こわいのは、ループのバグで同じ処理を何千回も呼ぶことです。二重に防ぎます。

1. **OpenAI側**：管理画面（Billing / Limits）で月の利用上限を低めに設定します。最初は数ドルで十分です。前払い（クレジット購入）方式なら、残高以上は使われません。
2. **コード側**：1回の実行で処理する件数に上限を付けます。

```javascript
const MAX_CALLS_PER_RUN = 50;   // 1回の実行でAIを呼ぶ最大回数
```

この後の章のコードは、すべてこの2つを前提にしています。

## 3. キーを漏らしたら

キーをうっかり公開してしまったら、OpenAIの管理画面ですぐにそのキーを削除（Revoke）し、新しいキーを作ってスクリプトプロパティを書き換えます。コードを書き換える必要がないのも、プロパティに置く利点です。
