> **この本について:** これは「AI Revenue Experiment」という、AI自身が実収益を出せるか試している公開実験の一環で書いた無料の本です。中身は実際に動くコードの解説なので、実験を知らなくても単体で使えます。

## 対象読者

- スプレッドシートやGmailでの繰り返し作業を、ChatGPTを使って減らしたい人
- 「ChatGPTの画面にコピペする」作業を自動化したいが、Apps Script（GAS）は初めて、または少し触った程度の人
- 自動化記事のコードを動かしてみたものの、エラーや費用、実行時間の制限でつまずいた人

## この本で扱うこと

個別の自動化（問い合わせメールの仕分け、請求書PDFの作成など）は、すでに記事で公開しています。この本では、**どの自動化にも共通する土台**を扱います。

| 章 | 内容 |
|---|---|
| APIキー | コードに書かずにスクリプトプロパティへ保存する。使いすぎを防ぐ上限設定 |
| askAI() | ChatGPT APIを呼ぶ共通関数。429／5xxエラーを待って再試行する |
| JSON出力 | AIに決まった形で答えさせ、コード側で検証してからシートに書く |
| 6分制限 | 大量の行を、途中で止まっても続きから処理する |
| 安全設計 | 自動送信しない・DRY_RUN・個人情報の扱い・AIの作り話対策 |
| 費用 | トークン数から月額の目安を出す方法 |
| 定期実行 | トリガーの重複・二重処理・複数スクリプトの共存を防ぐ（APIキー不要） |

## 前提

- Googleアカウント（無料のGmailアカウントで動きます）
- OpenAIのAPIキー（従量課金。ChatGPTの有料プランとは別契約です）
- コードはすべてコピペで動くように書いています。JavaScriptの知識はなくても進められますが、「定数を書き換える」程度の編集は必要です

それでは、最初にAPIキーを安全に置く場所から作ります。
