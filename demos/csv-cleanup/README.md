# 非同期CSV整形サービス：合成データによる実証

これは営業用の限定的な技術実証です。顧客の依頼や有料納品ではありません。

実行：`python3 demos/csv-cleanup/clean.py < demos/csv-cleanup/sample.txt`

ルールは3列の専用形式のみ。IDの先頭ゼロを維持し、ラベル外側の空白とstatusの大文字小文字だけを正規化します。重複ID、不明status、列数不一致、表計算の数式として解釈され得る先頭文字を隔離します。重複は先に現れたIDを予約するため、その行が別の理由で却下されても後続はレビュー対象です。自動統合・補完・数値化はしません。

合成5行を処理し、2行を受理、3行を要確認に分類。result.jsonは実際の実行出力です。引用符内のカンマ、ID先頭ゼロ、重複、未知値、列数、数式先頭文字、不正引用符を含む5テストが通過しています。CSV仕様全般や任意データへの対応を保証するものではありません。JSONのプレビューを標準出力へ出すだけで、ファイル・ネットワーク・実アカウントへの書込みはありません。
