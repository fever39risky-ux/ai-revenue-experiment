問い合わせ対応の実務例 · 登録不要

フォームの問い合わせ、
「誰が見るか」までを自動に。

Googleフォームで問い合わせを受けていると、届いた内容を読んで「見積もりか、クレームか、予約か」「急ぎか」を判断し、担当者に回す作業が毎回発生します。Google Apps Script（GAS）と ChatGPT の API を使うと、フォーム送信のたびにAIが種別・緊急度・1行要約を付けて回答シートに記録し、種別ごとの担当者へ通知メールを送るところまで自動にできます。

1. 仕組み（3ステップ）

  1. フォームの回答をスプレッドシートにリンクし、そのシートに GAS を入れて「フォーム送信時」トリガーを設定
  2. 送信されるたびに AI が本文を読み、種別（見積もり／不具合・クレーム／予約・日程／その他）・緊急度（高／中／低）・40字の要約を JSON で返す → シート右端の3列に記録
  3. 種別ごとに決めた担当アドレスへ通知。緊急度「高」は件名に【至急】が付く。元の本文も通知に添付
フォームの本文（例）AI種別緊急度
昨日納品いただいたシステムにログインできません。本日中に復旧をお願いします。不具合・クレーム高
来月の社内研修（20名）の見積もりをお願いできますか。見積もり中
土曜日は営業していますか？その他低

判定例はイメージです。実際の判定は本文次第で揺れるため、通知には必ず元の本文を添えます。

2. まず無料で：仕分けプロンプト

スクリプトを入れる前に、ChatGPT に貼って自社の問い合わせがどう仕分けられるか確かめられます。

次のお問い合わせ本文を社内向けに仕分けてください。
本文に書かれた事実だけを使い、推測で補わないこと。
JSONのみで答えてください:
{"category": "見積もり" / "不具合・クレーム" / "予約・日程" / "その他" のどれか,
 "urgency": "高" / "中" / "低" のどれか,
 "summary": "40字以内の日本語要約"}
緊急度の目安: 高=業務停止・強い不満・当日中の対応要求、
中=数日内に対応、低=情報提供や質問のみ。
---
［ここに問い合わせ本文を貼る］
運用が壊れない3つのコツ：①選択肢をコード側で固定し、一覧に無いラベルが返ったら「その他」に丸める（通知先の振り分けが壊れない）。②JSON出力＋temperature 0 で揺れを減らし、AIが失敗しても「その他・中」で通知だけは必ず飛ばす（取りこぼしゼロ）。③最初は DRY_RUN でメールを送らずログだけ確認する。

3. お客様への返信はAIに書かせない

自動返信までAIに任せると、「在庫あります」「明日伺えます」のような本文に無い約束を書かれる事故が起きます。この仕組みの範囲は社内向けの仕分けと要約まで。誤判定しても社内の人が本文を見れば気づける範囲に留めるのが、小さな会社で安全に始めるコツです。

  • 個人情報の扱いは社内ルールを確認。本文は OpenAI の API に送信されます。
  • 費用の目安：gpt-4o-mini なら問い合わせ1件あたり1円未満（本文の長さによる）。
