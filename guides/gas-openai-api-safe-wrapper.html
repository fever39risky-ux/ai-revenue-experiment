実験トップ

GAS×AIの土台 · 登録不要

GASからChatGPTを呼ぶなら、
まず「安全な共通関数」を1つ。

ネットのサンプルをそのまま業務に使うと、APIキーの直書き・混雑時の429エラーで停止・トリガーの二重登録で課金が膨らむ・6分制限で途中終了、のどれかに必ず当たります。呼び出しを askAI("プロンプト") という1つの関数に集約して、対策をまとめて効かせるのが一番ラクです。

1. 5つの落とし穴と対策

落とし穴無いとどうなるか対策
APIキーをコードに直書きコードを共有・スクショした瞬間に漏れるスクリプト プロパティ
429 / 5xx エラー混雑した時間帯に数十行に1回止まるRetry-After→指数バックオフ
残高不足の 429待っても直らないのに待ち続けるinsufficient_quota は即エラー
課金の暴走トリガー二重登録・ループで請求が増える1日の呼び出し上限
同じ文章の再送お金も時間も余分にかかるCacheService で6時間再利用
GASの6分制限途中終了し、どこまで処理したか分からない5分で自主停止→続きから

2. APIキーは「スクリプト プロパティ」へ

  1. Apps Script エディタ左の「⚙ プロジェクトの設定」を開く
  2. 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
  3. プロパティ名 OPENAI_API_KEY、値に sk-... を入れて保存

コードにはキーが残らないので、スクリプトをコピーして人に渡しても漏れません（プロジェクトの編集権限を渡すと見える点だけ注意）。

3. 心臓部：再試行してよいエラーだけ再試行する

const code = res.getResponseCode();
const text = res.getContentText();
// 残高不足の 429 は待っても直らないので即エラー
const quota = text.indexOf('insufficient_quota') >= 0;
const retryable = (code === 429 && !quota) || code >= 500;
if (!retryable || i === MAX_RETRIES) {
  throw new Error('OpenAI API エラー HTTP ' + code + ': ' + text.slice(0, 300));
}
// Retry-After があれば従い、無ければ 1秒→2秒→4秒 ＋ゆらぎ
const h = res.getHeaders();
const ra = Number(h['Retry-After'] || h['retry-after']);
const waitMs = ra > 0 ? ra * 1000 : Math.pow(2, i) * 1000 + Math.floor(Math.random() * 500);
Utilities.sleep(Math.min(waitMs, 20000));

muteHttpExceptions: true を付けて UrlFetchApp を呼ぶと、エラー時も例外にならずに本文（エラーの種類）を読めます。

4. 1日の上限は LockService で数える

時間主導トリガーが同時に動くと、単純に getProperty → +1 → setProperty では数え漏れが出ます。LockService.getScriptLock() で囲んでから数え、日付キー（例：ai_calls_20260924）で管理すれば、翌日には自動でリセットされます。最初の上限は 50〜100回くらいから始めるのが安全です。

5. 大量の行は「5分で止まって、続きから」

考え方：ループの先頭で経過時間を見て、5分を超えたら自分で return。結果列が埋まっている行は飛ばすので、もう一度実行すれば空いている行から再開します。エラーの行には ERROR: … と書いておき、消せば次回やり直し。上限に達したらその場で止めます。

6. 注意点

  • JSONモード（response_format: json_object）を使うときは、プロンプトのどこかに「JSON」という単語が必要です（OpenAIの仕様）。
  • 無料の Google アカウントでは UrlFetchApp の1日の呼び出し回数にも上限があります。大量処理は数日に分けてください。
  • 送る文章は OpenAI の API に送信されます。個人情報を流さない・社内ルールで利用が許可されているかを先に確認してください。
  • お客様に送る文章をAIに書かせる場合は、送信せず下書きに留めて人が確認する運用をおすすめします。
