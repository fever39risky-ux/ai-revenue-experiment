GAS×Gmail · 登録不要 · コード全文

スプレッドシートから差し込みメールを、
「Gmailの下書き」で一括作成する。

案内・お礼・請求のお知らせなど、宛名と一部だけ違うメールを何十通も送る作業は、Google Apps Script（GAS）で下書きまで自動化するのが一番安全です。いきなり送信せず、Gmail の下書きフォルダに並べて、人が目で確認してから送るので誤送信が起きません。

1. シートの形

A: メールB: 会社名C: 氏名D: メモE: 状態
taro@example.com山田商店山田 太郎先月初回注文（空欄）
hanako@example.com佐藤工務店佐藤 花子見積もり中（空欄）

1行目は見出し。E列「状態」が空欄の行だけ処理し、下書きを作ったら「下書き作成済」と書き込みます（二回実行しても二重に作られません）。

2. 本文テンプレートは別シートに

シート「テンプレート」の A1 に件名、A2 に本文を書きます。{{会社名}} {{氏名}} のように1行目の見出しと同じ名前を二重波かっこで囲むと、その列の値に置き換わります。

A1: 【{{会社名}}様】10月の営業日のお知らせ
A2: {{会社名}}
{{氏名}} 様

いつもお世話になっております。
10月の営業日をお知らせいたします。
（以下略）

3. コード全文（コピペで動きます）

スプレッドシートの「拡張機能 → Apps Script」に貼り付けて、createMergeDrafts を実行します。初回だけ Gmail とスプレッドシートへのアクセス許可を求められます。

const SHEET = '宛先';         // 宛先リストのシート名
const TEMPLATE = 'テンプレート'; // A1=件名, A2=本文
const STATUS_COL = 5;         // E列「状態」
const LIMIT_MS = 5 * 60 * 1000; // 6分制限の手前で止める

function createMergeDrafts() {
  const start = Date.now();
  const ss = SpreadsheetApp.getActive();
  const sh = ss.getSheetByName(SHEET);
  const tpl = ss.getSheetByName(TEMPLATE);
  const subjectTpl = String(tpl.getRange('A1').getValue());
  const bodyTpl = String(tpl.getRange('A2').getValue());
  const values = sh.getDataRange().getValues();
  const head = values[0].map(String);
  let made = 0;

  for (let r = 1; r < values.length; r++) {
    if (Date.now() - start > LIMIT_MS) break;       // 続きは次回
    const row = values[r];
    if (String(row[STATUS_COL - 1]).trim() !== '') continue; // 処理済み
    const to = String(row[0]).trim();
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(to)) {
      sh.getRange(r + 1, STATUS_COL).setValue('ERROR: メール不正');
      continue;
    }
    const fill = s => s.replace(/\{\{(.+?)\}\}/g, (m, key) => {
      const i = head.indexOf(key.trim());
      const v = i >= 0 ? String(row[i]).trim() : '';
      return v !== '' ? v : m; // 列が無い・空欄は差し込み漏れとして残す
    });
    const subject = fill(subjectTpl);
    const body = fill(bodyTpl);
    if (/\{\{.+?\}\}/.test(subject + body)) {    // 置き換え漏れは作らない
      sh.getRange(r + 1, STATUS_COL).setValue('ERROR: 差し込み漏れ');
      continue;
    }
    GmailApp.createDraft(to, subject, body);        // 送信はしない
    sh.getRange(r + 1, STATUS_COL).setValue('下書き作成済 ' +
      Utilities.formatDate(new Date(), 'Asia/Tokyo', 'MM/dd HH:mm'));
    made++;
  }
  SpreadsheetApp.getActive().toast(made + '件の下書きを作成しました');
}

ポイントは3つ：①状態列で処理済みを管理（二重作成なし・止まっても続きから）、②差し込み漏れ（列名の違い・空欄で {{…}} が残った）行は作らずERROR表示、③createDraft なので絶対に送信されない。

4. 送るときの注意（送信上限）

  • 下書きは Gmail 画面から1通ずつ確認して送ります。スクリプトで自動送信（GmailApp.sendEmail）に切り替える場合、Apps Script からの送信には1日の宛先数の上限があります（無料の Gmail アカウントは約100件／日、Google Workspace は約1,500件／日）。残りは MailApp.getRemainingDailyQuota() で確認できます。
  • 一斉送信の広告メールは特定電子メール法の対象です。取引のある相手への業務連絡に使い、宣伝目的の配信には同意取得と配信停止の案内を入れてください。
  • BCCでまとめて送るより、1人1通の方が宛先の見落としや漏えいが起きにくく、返信も管理しやすくなります。

5. オプション：ChatGPTで「一言だけ」個別に添える

本文をまるごとAIに書かせると、事実と違う約束を書いたり、毎回言い回しが変わって確認が大変になります。おすすめは本文は固定テンプレート、D列「メモ」から冒頭の一言だけAIに作らせるやり方です。テンプレートに {{ひとこと}} を置き、F列を「ひとこと」列にして、先に次の関数で埋めます（空欄の行だけ）。

// プロンプト例（askAI は下の安全な共通関数のページを参照）
const prompt = 'あなたは日本の中小企業の事務担当です。次のメモから、' +
  '取引先へのメール冒頭に添える自然な一文（40字以内）を1つだけ書いてください。' +
  'メモに無い事実（日付・金額・約束）は書かないこと。\nメモ：' + memo;

APIキーの隠し方・429エラーの再試行・1日の上限つきの呼び出し関数は GASからChatGPT APIを安全に呼ぶ askAI() にまとめています。AIが作った一言もシート上で確認・修正してから下書きを作れるのが、この2段階方式の利点です。

よくあるつまずき：「{{氏名}}」が置き換わらない → 見出しに余分な空白があるか、全角/半角の違いです。見出しセルをテンプレートからコピーして貼ると確実です。改行が消える → A2 セル内の改行は Alt+Enter（Mac は ⌘+Enter）で入れます。
