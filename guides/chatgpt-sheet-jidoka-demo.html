「本当に動くの？」に答える実演
――スプレッドシートをAIで一括処理するスクリプトの中身

ひとり社長・個人事業主・少人数チーム向け／登録不要／買う前に中身を確認できます

「そのまま動くGoogle Apps Scriptが入っている」と書かれても、中身が見えなければ判断できません。このページでは、ツールキットに付属するスクリプト①「AI一括処理」のコード全文と、実際の処理イメージ（Before→After）をそのまま公開します。買う前に、何をするツールなのかを確かめてください。

これは何のページ？：付属スクリプトの実物コードと、それを使ったときの代表的な入出力例です。スクリーンショットの捏造や、盛った成果の主張はしません。出力はAIモデル（gpt-4o-mini）と指示文の内容で変わり、実行はあなた自身のGoogleアカウント内・あなた自身のAPIキーで行われます。当方があなたのデータを預かることはありません。

スクリプト①がやること（1行で）

A列に並んだテキストを1行ずつAIに渡し、指示どおりに処理した結果をB列へ書き込む――これをボタン1回で最大200行まで一括実行します。「毎回ChatGPTに貼る」作業そのものが消えます。

実演①：問い合わせを自動で分類する

スクリプトの初期設定は「問い合わせをクレーム / 質問 / 要望 / その他のいずれか一語で分類する」になっています。設定はこの1行を書き換えるだけ：

INSTRUCTION: '次の問い合わせを「クレーム / 質問 / 要望 / その他」のいずれか一語だけで分類して: {input}'

A列に問い合わせを貼り、メニューの「AIツール → A列をB列へ一括処理」を押すと、B列が埋まります。処理イメージ：

A列（貼り付ける入力）B列（AIが自動で記入）
先週注文した商品がまだ届きません。いつ発送されますか？質問
対応がとても遅く、正直がっかりしました。改善してほしいです。クレーム
領収書の宛名を会社名に変更してもらえますか？質問
月額ではなく買い切りのプランも用意してほしいです。要望
いつもお世話になっております。特に問題はありません。その他

※ 分類ラベルはあなたの業務に合わせて自由に変更できます（例：「緊急/通常/保留」「見込み度：高/中/低」など）。

実演②：長文を1行要約に変える

指示文を差し替えるだけで、同じスクリプトが別の作業をします。例：

INSTRUCTION: '次の文章を、事実だけを使って40字以内の日本語1文に要約して。推測や誇張はしない: {input}'
A列（長いメモ・議事録の抜粋）B列（AIが自動で記入）
本日の打ち合わせでは新機能のリリース時期を協議。開発は9割完了だが検証環境の不具合で最終テストが遅延、来週再判断することで合意した。最終テストが遅延、来週リリース時期を再判断で合意。
顧客より請求書の項目名について問い合わせ。担当が確認し、次回発行分から表記を統一する方針で返信済み。追加費用は発生しない。請求書の表記を次回から統一、追加費用なしで回答済み。

※ 「事実だけを使う／誇張しない」という制約を指示文に入れてあるのがポイントです。AIが自信満々に嘘（捏造）を返すのを抑えます。

付属スクリプト①の全文（そのまま貼れます）

ごまかしなく、実際に同梱されているコードを載せます。非エンジニアが触るのは先頭の設定ブロックだけです（APIキーと、やらせたい指示文）。

const CONFIG = {
  API_KEY: 'ここにOpenAI APIキー(sk-...)',   // ← ここだけ変更
  MODEL: 'gpt-4o-mini',                        // 安価で十分。精度重視なら 'gpt-4o'
  INSTRUCTION: '次の問い合わせを「クレーム / 質問 / 要望 / その他」のいずれか一語だけで分類して: {input}',
  INPUT_COL: 1,     // A列 = 入力
  OUTPUT_COL: 2,    // B列 = 出力
  START_ROW: 2,     // 1行目は見出しとして飛ばす
  MAX_ROWS: 200,    // 一度に処理する最大行数（暴走防止）
  TEMPERATURE: 0
};

function batchProcess() {
  const sheet = SpreadsheetApp.getActiveSheet();
  const last = Math.min(sheet.getLastRow(), CONFIG.START_ROW + CONFIG.MAX_ROWS - 1);
  for (let row = CONFIG.START_ROW; row <= last; row++) {
    const input = sheet.getRange(row, CONFIG.INPUT_COL).getValue();
    const existing = sheet.getRange(row, CONFIG.OUTPUT_COL).getValue();
    if (!input || existing) continue;   // 空行・処理済みは飛ばす（再実行しても安全）
    const out = askAI(CONFIG.INSTRUCTION.replace('{input}', String(input)));
    sheet.getRange(row, CONFIG.OUTPUT_COL).setValue(out);
    Utilities.sleep(300);   // レート制限対策
  }
}

※ 抜粋です。実際の同梱ファイルには、メニュー追加（onOpen）、OpenAI呼び出し（askAI）、エラー時にB列へ「ERROR: …」と残す安全処理、完了トーストまで含まれます。もう1本のスクリプト②は「決まった集計を毎朝メールで自動送信」します。

ここが「ただのプロンプト集」との違い

  • 処理済みの行は自動でスキップ：途中で止めても、もう一度押せば続きから。二重課金しません。
  • 暴走防止の上限（MAX_ROWS）：一度に処理する行数に上限があり、想定外の大量実行を防ぎます。
  • あなたのアカウント内で完結：スクリプトはあなたのGoogle＋あなたのAPIキーで動作。外部にデータを預けません。
  • コピペ導入：日本語の導入手順書（PDF・全4ページ）が、APIキー取得から貼り付け・つまずき対処まで案内します。
正直な前提：結果は対象業務・指示文・モデルにより変わります。収益や時短効果を保証する商品ではありません。OpenAIの利用料はご利用者負担です（gpt-4o-miniは非常に安価で、まず少額から試せます）。ChatGPT等の有料プランは不要です。
