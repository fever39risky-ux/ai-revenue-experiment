表計算×AIの実務例 · 登録不要

セルに =AI() と書くだけ。
ただし課金の落とし穴に注意。

アンケートの自由記述の要約、問い合わせの分類、商品説明の下書き。「1行ずつAIに聞きたい」作業は、Google Apps Script（GAS）で =AI("指示", A2) という自作関数を作ると表計算のまま片付きます。純正のAI機能が使えないプランや個人アカウントでも、OpenAI の API キーがあれば動きます。

1. こう使う

やりたいことセルに書く式
自由記述を要約=AI("30文字以内で要約して", B2)
分類（選択肢を固定）=AI("次のどれか1語で: 要望/不満/質問/その他", B2)
英訳=AI("自然な英語に翻訳して", B2)
商品説明の下書き=AI("この特徴から60文字の商品説明を", B2&" / "&C2)

分類は「選択肢を指示文の中で固定」するのが一番効きます。自由に答えさせると「要望（改善）」のような表記ゆれが出て集計できません。

2. 落とし穴は2つ

  1. 再計算のたびにAPIが呼ばれて課金が増える。カスタム関数は、ファイルを開く・行を並べ替える・参照先が変わる、で再実行されます。500行の表を開くたびに500回呼ばれる、が起こり得ます。
  2. 数百行に一気にコピーするとエラーだらけ。同時リクエストが集中して、API 側の混雑エラー（429）が大量に出ます。
対策は3段：①同じ「指示＋対象」の答えは6時間キャッシュして再課金しない。②空セルではAPIを呼ばない。③結果が埋まったら、メニュー「AI → 値で確定」で数式を消してただの値にする。確定した値は二度と再計算されないので、後で並べ替えても課金はゼロです。コピーは最初20〜30行ずつが安全です。

3. まず無料で：セルに入れやすい答えを返させる指示文

関数を作る前に、ChatGPT に数行貼って指示文を固めておくと、あとで表に入れたときのブレが減ります。

次の各行について、指示に対する答えだけを1行ずつ返してください。
前置き・説明・引用符・番号は付けない。分からない行は「不明」とだけ書く。
指示: 次のどれか1語で答えて: 要望/不満/質問/その他
---
配送が遅すぎる。もう頼みません
領収書の宛名は変更できますか
アプリにダークモードがあると嬉しい

期待する返答：「不満」「質問」「要望」。この3行が安定して返るようになってから、同じ指示文を =AI() に入れます。

4. 入れてはいけないデータ

  • セルの内容はそのまま OpenAI の API に送信されます。個人名・電話番号・住所などを流さない、社内ルールでAPI利用が許可されているかを先に確認してください。
  • 費用の目安：gpt-4o-mini で短い要約・分類なら、1,000行でも数十円程度です（文章の長さで変わります）。キャッシュと「値で確定」を使えば、同じ行に二度課金されません。
  • エラーは #AIエラー 401 のような原因が読める文字列で返すので、#ERROR! で原因不明、になりません。
