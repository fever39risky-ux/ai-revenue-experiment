日報、カレンダーに
もう書いてある。

毎日の日報を書くとき、結局やっているのは「今日のカレンダーを見返して、予定と時間を書き写す」作業です。Google Apps Script（GAS）と ChatGPT の API を使うと、毎日18時にその日の予定から日報の下書きを作り、Gmailの下書きフォルダに入れておくところまで自動にできます。開いて所感を一言足して送るだけです。

1. 仕組み（3ステップ）

  1. GAS がその日の Google カレンダーの予定を集める（「私用」「ランチ」など除外したい語を含む予定は捨てる）
  2. 予定ごとの時間と、重なりを除いた合計時間を GAS が計算して「事実」として確定
  3. AI は事実を日報の文章にするだけ。結果は Gmail の下書きに入り、自動送信はしない
カレンダーの予定（例）日報に載る時間
10:00-11:00 A社 定例MTG
10:30-12:00 A社 資料作成		A社：2時間
（重なった30分は1回だけ）
15:00-16:30 採用面接1時間30分
12:00-13:00 ランチ載せない

合計は 3時間30分。AIに「合計何時間？」を任せると重なりを二重に足しがちなので、数字は必ずコードで計算します。

2. まず無料で：日報プロンプト

スクリプトを入れる前に、今日の予定を書き写して ChatGPT に貼れば同じ形の日報が作れます。

あなたは社内日報の下書きを書くアシスタントです。
下の「事実」だけを使い、書かれていない成果・数字・人名を足さないこと。
時刻と合計時間は事実の数字をそのまま使い、計算し直さないこと。
構成: 「本日の業務」（箇条書き）、「合計時間」、「明日の予定」、
最後に「所感: （ここに一言）」の空欄。社内向けの敬語で400字以内。
---
【今日の予定】
- 10:00-11:00 A社 定例MTG
- 10:30-12:00 A社 資料作成
- 15:00-16:30 採用面接
【予定の合計時間（重複を除く）】3時間30分
【明日の予定】
- 09:00 A社 レビュー
日報を「盛らせない」3つのコツ：①合計時間は自分（またはコード）で出して「計算し直さない」と指示する。②「書かれていない成果を足さない」と明記する（日報で一番まずいのは、やっていない仕事が書かれていること）。③所感は空欄で返させ、人が一言書く。

3. 送信はしない。下書きに置くだけ

自動化で怖いのは、AIの文章がそのまま上司に飛ぶことです。この仕組みは Gmail の下書きを作るところまで。AIが失敗した日も、予定一覧と合計時間だけの素朴な下書きは必ず作るので、日報の習慣が途切れません。

  • 予定の説明欄にお客様の個人情報を書いている場合は、説明欄をAIに送らない設定で使ってください。予定の内容は OpenAI の API に送信されます。
  • 費用の目安：1日1回・予定の一覧だけなので、gpt-4o-mini なら1回あたり1円未満。土日と予定ゼロの日はAPIを呼びません。

4. コード全文（無料）

コピペで動くコード全文とトリガー設定の手順は Zenn の解説記事として順次公開します。APIキーの安全な置き場所・429エラー時の再試行・6分制限の回避など、GAS×ChatGPT自動化の共通の土台は無料の Zenn 本にまとめています。
