問い合わせ対応の実務例 · 登録不要

Gmailの問い合わせ返信、
「下書きまで」をAIに任せる。

フォーム通知や問い合わせメールが来るたびに、ゼロから返信を書いていませんか。Google Apps Script（GAS）と ChatGPT の API を使うと、届いたメールの分類と返信の下書きまでを自動で用意できます。送信は人が確認してから。これが事故らない使い方です。

1. 仕組み（3ステップ）

  1. Gmail のフィルタで、問い合わせメールに「問い合わせ」ラベルが付くようにする
  2. GAS が1時間おきに未読のラベル付きスレッドを読み、AI が「緊急・質問・要望・クレーム・その他」に分類
  3. AI が返信文を作り、Gmail の下書きとして保存（自動送信はしない）

分類と下書きは1回のAPI呼び出しでまとめて取るので、gpt-4o-mini なら1件あたりの費用はごく小さく済みます（従量課金・利用量により変動）。

2. まず無料で試す：返信方針プロンプト

スクリプトを入れる前に、ChatGPT に手で貼って品質を確かめられます。［ ］の部分をあなたのお店・事業に合わせて書き換えてください。

あなたは丁寧で簡潔な日本語のカスタマーサポート担当です。
相手の名前が分かれば宛名を付け、要件を1文で受け止めてから回答します。
回答に使ってよい確定事実は次だけです。これ以外の在庫・価格・日程・規定は
断定せず「確認して折り返します」と書いてください。
- 営業時間：［平日10:00〜18:00］
- 返信目安：［1営業日以内］
- ［料金・キャンセル規定などを1行ずつ］
過度な謝罪や誇張はしません。

次の問い合わせに対する返信文だけを書いてください（署名は不要）。
---
［問い合わせメールの本文を貼る］
いちばん大事な一行：「確定事実以外は断定せず『確認して折り返します』と書く」。AI は分からない在庫や日程を"それっぽく"埋めがちです。言ってよい事実を明示し、それ以外を断定させないだけで、誤った約束をする事故がかなり減ります。

3. 自動化するなら（コードは無料で公開中）

GAS のコード全文と解説は Zenn で無料公開しています → GAS×ChatGPTでGmail問い合わせを自動仕分け・返信下書き（Zenn）

  • 必要なもの：Google アカウントと OpenAI の API キー（従量課金）。ChatGPT の有料プランは不要です。
  • メールはあなたの Google アカウント内で処理され、本文は OpenAI API に送信されます。個人情報を含むメールの扱いは、各自の運用ルールに従ってください。
  • 下書きを作るだけなので、深夜や休日に動いても外部に勝手に送られることはありません。
