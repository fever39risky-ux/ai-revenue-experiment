実験トップ

会議後の事務作業の実務例 · 登録不要

議事録づくり、
「要点・決定事項・TODO」までを自動に。

会議のあと、文字起こしやメモを読み返して「結局なにが決まったか」「誰がいつまでに何をやるか」を抜き出す。これが議事録作成で一番時間のかかる部分です。Google Apps Script（GAS）と ChatGPT の API を使うと、スプレッドシートに貼ったメモを、要点・決定事項・TODOに整形してシートに記録するところまで自動にできます。

1. 仕組み（3ステップ）

  1. シートのA列に、会議の文字起こし・殴り書きメモを1会議1行で貼る
  2. メニューから実行すると、AI が「要点（3つまで）」「決定事項」「TODO（担当者 - やること - 期限）」の3見出しに整形してB列に書き込む
  3. C列に宛先があれば参加者へまとめを送る（空なら記録だけ）。処理済みの行は飛ばすので、再実行しても二重処理しない

2. まず無料で：憶測を書かせない議事録プロンプト

スクリプトを入れる前に、ChatGPT に貼って仕上がりを確かめられます。［ ］の中に会議メモを貼ってください。

以下は会議の文字起こしまたはメモです。
事実だけを使い、憶測や創作は書かないでください。
次の3つの見出しで日本語にまとめてください。
# 要点（3つまで、箇条書き）
# 決定事項（箇条書き。決定がなければ「決定事項なし」と書く）
# TODO（「担当者名 - やること - 期限」の形式で箇条書き。
  担当者や期限が本文に無い項目は「未定」と書く）
---
［ここに会議メモを貼る］
ポイントは2行だけ：「事実だけを使う」と「本文に無い担当者・期限は『未定』と書く」。これがないと、AI は決まっていない担当者や期限を“それっぽく”補ってしまいます。議事録で一番困る事故は、誰も言っていない約束が文書に残ることです。

3. 運用のコツ

  • 長い会議は雑談を削ってから。スクリプトは先頭8,000字だけを AI に渡します（トークン代の上限）。
  • 自動送信の前に一度目で見る運用も可能。C列を空にしておけば記録だけ行い、内容を確認してから手で共有できます。
  • 社外秘の会議は社内ルールを確認。メモの内容は OpenAI の API に送信されます。

コード全文（無料）は Zenn の解説記事として公開予定です。スクリプトをすぐ使いたい方は下のセットに含まれています。
