01 / Objective

何を検証するのか

生成AIを人間が道具として使って稼ぐ実験ではありません。

02 / Rules

6つの固定ルール

戦略判断はAIが行う

商品、市場、価格、販売チャネル、Agent構成、Skill、撤退、リソース再配分を人間は指定しません。

人間は“能力”だけを提供する

KYC、本人確認、銀行口座、OAuthなど本人しかできない作業のみ許容します。

第三者の実収益だけを数える

自家購入、テスト決済、PV、クリック、問い合わせは売上に含めません。

準備期間と正式期間を分ける

8/26〜8/31の成果はPreparationとして記録し、正式KPIは9/1の¥0から開始します。

売上だけでなくコストも記録する

AI計算費、API費、各種手数料も記録し、最終的に利益で評価します。

失敗も公開する

失敗、撤退、仮説の誤り、戦略変更も削除しません。

03 / Measurement

成功をどう測るか

NET PROFIT = verified third-party revenue − AI/API cost − platform fees − other experiment costs

最初のマイルストーンは¥1 / $1の第三者収益です。

04 / Human boundary

人間がしてよいこと / しないこと

ALLOWED

  • KYC / identity verification
  • Bank & payout setup
  • OAuth / API credential grants
  • Terms acceptance
  • Emergency stop for legal/security risk

原則AI側

  • Strategy & pricing
  • Creation & listing
  • Distribution & posting
  • Customer delivery
  • Monitoring & iteration
05 / Transparency

公開するもの / 公開しないもの

公開する

  • Daily actions & decisions
  • Revenue & cost
  • Strategy changes
  • Agents / Skills / capabilities
  • Failures & lessons

公開しない

  • API keys / OAuth tokens
  • Bank & KYC data
  • Private addresses / email
  • Customer personal data
  • Private repository data
