Google Sheets Invoice Generator

Bulk PDF invoices + Gmail drafts from one spreadsheet row each. Setup takes about 5 minutes. No coding, no add-on, no subscription.

What's in the download

  • InvoiceGenerator.gs: the script you paste into your Google Sheet
  • sample_invoices.csv: two example rows (optional, you can import it instead of using "Set up sheet")
  • Setup-Guide.pdf: this guide

Step 1: Add the script to a Google Sheet

  1. Create a new Google Sheet (sheets.new).
  2. Click Extensions → Apps Script.
  3. Delete the sample function myFunction(), then paste the whole contents of InvoiceGenerator.gs. Click the save icon.

Step 2: Enter your business details

At the top of the script, edit the CONFIG block:

SettingWhat to put
BUSINESS_NAME / BUSINESS_DETAILSYour name or company, address, email, tax ID (shown on every invoice)
PAYMENT_DETAILSHow clients pay you (bank, PayPal, etc.)
CURRENCY_SYMBOL / CURRENCY_DECIMALSe.g. '$', '€', '£'; use 0 decimals for currencies like JPY
TAX_RATE / TAX_LABELe.g. 0.2 and 'VAT'. Use 0 for no tax line.
DUE_DAYSDays until payment is due (default 14)
INVOICE_PREFIXInvoice numbers look like INV-2026-0001 and count up automatically
CREATE_GMAIL_DRAFTtrue = also create an email draft with the PDF attached
OPENAI_API_KEY (optional)Leave empty to use the built-in email template. If you add a key, AI writes a friendlier email. AI never touches the amounts.

Step 3: Create the Invoices sheet

Reload the spreadsheet. A new Invoices menu appears. Click Invoices → Set up sheet (first time). This creates the columns and two example rows. The first time, Google asks you to authorize the script. It is your own script running in your own account. Click Advanced → Go to (project) if Google shows the "unverified app" screen, which is normal for personal scripts.

Step 4: Fill rows and create invoices

One row = one invoice. Put line items in one cell, one per line (Ctrl/Cmd+Enter makes a new line inside a cell):

Homepage redesign ; 1 ; 450
Extra page ; 2 ; 120

Then click Invoices → Create invoices for new rows. For each row not yet marked Done, the script:

  1. calculates subtotal, tax and total,
  2. saves a PDF to the Drive folder Invoices (PDF),
  3. creates a Gmail draft to the client with the PDF attached,
  4. writes Done, the invoice number and the PDF link back into the row.

Nothing is ever sent automatically. Open Gmail → Drafts, check the email, and press Send yourself.

Troubleshooting

  • Status shows "ERROR: no valid line items": check each line is Item ; Qty ; Unit price with semicolons.
  • No Invoices menu: reload the sheet; make sure the script was saved.
  • Re-issue an invoice: clear the Status cell of that row and run again (it gets a new number).
  • Change the invoice layout: edit the makePdf_ function. Every line is commented.

Important

You are responsible for checking that your invoices meet the tax and invoicing rules of your country. The script calculates totals with standard rounding to 2 decimals. Check amounts before sending. Google's normal Apps Script daily quotas apply (plenty for small businesses).
