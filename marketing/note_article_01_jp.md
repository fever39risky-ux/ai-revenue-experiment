## タイトル

ChatGPTに事務仕事をやらせると「それっぽい嘘」で事故る。防ぐ一文と、コピペで使える実務プロンプト

## 本文（ここからそのまま貼り付け）

ChatGPTを仕事で使い始めた人が、最初にやらかすのはだいたい同じです。

「それっぽいけど、事実じゃない」返事を、そのまま客先に出してしまう。

AIは知らないことでも自信満々に埋めてきます。存在しない条文、盛られた数字、言ってもいない仕様。悪気はないんですが、実務ではこれが一番こわい。

僕がいろんな事務作業でChatGPT／Claudeを使ってきて、効果が大きかったのは、賢いテクニックよりも、**プロンプトに最初から「嘘をつかせない制約」を入れておくこと**でした。

具体的には、この一文を足すだけです。

> わからないことは推測せず、「確認して折り返します」と書いて。数字や固有名詞は勝手に作らない。

これだけで、事実の捏造はかなり減ります。ゼロにはなりません。最後は人が確認する前提は変わりません。でも「そのまま出せる下書き」に一気に近づきます。

---

### そのまま貼れる、事務プロンプトを3つだけ

長く説明するより、明日から使えるやつを置いておきます。`"""` の中に自分の材料を貼るだけです。

**① メールの一次返信ドラフト**

```
あなたは[会社名]の担当者です。下のメールへの返信を書いてください。
ルール：丁寧に、120字程度、事実を勝手に作らない（不明点は「確認のうえ折り返します」と書く）、署名は不要。
メール："""（ここに貼る）"""
```

白紙から書き出す待ち時間が消えます。あなたは選んで送るだけ。

**② 打ち合わせの文字起こし → 議事録＋タスク**

```
下の文字起こしから、次の3つを作ってください。
1) 議事録（箇条書き・150字以内）
2) アクション項目の表（担当者／期限が言及されていれば記入）
3) 未確定の論点
はっきりしない項目は「TBD」と明記。文字起こし："""（ここに貼る）"""
```

30分かけて書いていた議事録が、30秒の確認作業になります。TBDを明記させるのがポイントで、これがない議事録は「決まってないこと」を決まったように書いてしまう。

**③ 長文を30秒で要約**

```
下の内容を、忙しい人が30秒で把握できる重要ポイント3点に要約してください。
誇張はしない。"""（ここに貼る）"""
```

転送する前に「で、結局なに？」を自分でつかめる。地味ですが効きます。

### 「毎回貼る」のが面倒になったら、次は自動化

上のプロンプトは手で貼って使うものです。ただ、同じ作業を毎日・毎週やるなら、そのうち「貼る」こと自体が面倒になります。

そこから先は、スプレッドシートの1列をAIで全行いっぺんに処理したり、毎朝の集計を自動でメールに送ったり、という「作業そのものを消す」方向に進めます。ここはプロンプトではなく、ちょっとした仕組み（スクリプト）の話になるので、また別で書きます。
