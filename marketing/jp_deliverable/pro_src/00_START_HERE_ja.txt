AI業務自動化キット PRO — さいしょにお読みください
=================================================

このキットは「AIの使い方の説明」ではなく、あなたのGoogleスプレッドシート／
Gmailでそのまま動く自動化スクリプト5本をお渡しするものです。コードが
書けなくても、コピー＆ペースト中心で導入できます。

【まず開くもの】
1. 「01_setup_guide_ja.pdf」（日本語の導入手順書・基本2本用）
   OpenAI APIキーの取得から、スクリプトの貼り付け・設定・トラブル対処まで。
2. 「02_pro_addendum_ja.txt」（PRO追加3本の導入ガイド）
   追加スクリプトはこちらの手順で導入します。

【同梱物（スクリプト5本）】
- 3_ai_batch.gs                  … シート1列をAIで一括処理（分類・要約・翻訳など）
- 4_daily_report.gs              … 毎朝の自動サマリーメール（3_ai_batch.gs と併用）
- 6_gmail_inquiry_autoreply.gs   … 【PRO】Gmail問い合わせの自動仕分け＆下書き返信
- 7_invoice_pdf_ai_email.gs      … 【PRO】請求書PDF自動作成＋AI添え状メール下書き
- 8_meeting_minutes_ai_summary.gs… 【PRO】議事録AI自動要約（要点/決定事項/TODO）＋自動メール

【その他の同梱物】
- 01_setup_guide_ja.pdf … 日本語の導入手順書（基本2本用・全4ページ）
- 02_pro_addendum_ja.txt … PRO追加3本の導入ガイド
- 2_prompt_library.csv … 実務プロンプト20本（Sheets/Notionに取り込み可）
- 5_invoice_template.csv … 請求書テンプレート
- 1_AI_Automation_Toolkit.pdf … ワークフロー集（English / bonus）
- START_HERE.txt … English quick start

【必要なもの】
- Google アカウント（スプレッドシート・Gmail）
- OpenAI APIキー（従量課金。手順書に取得方法あり。ChatGPTの有料プランは不要）

【設計方針（共通）】
- 「AIは文章・下書きだけ、金額や送信の確定は人間またはコード」と役割を分けています。
- どのスクリプトも自動送信・自動確定はしません（下書き作成／メール本文の要約通知まで）。
- 5本はそれぞれ独立して動きます。全部を一度に使う必要はなく、必要なものだけ導入できます。

【ご注意】
- スクリプトはあなたのGoogleアカウント内で動きます。当方がデータを預かることはありません。
- APIの利用料はご利用者負担です（gpt-4o-miniは非常に安価。まず少額から）。
- 収益・時短効果を保証するものではありません。効果は対象業務により変わります。
- アップデートは無料です。ご不明点は購入プラットフォームのメッセージでご質問ください。
