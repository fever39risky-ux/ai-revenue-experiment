AI業務自動化キット PRO — 追加3スクリプト 導入ガイド
=====================================================

このPRO版には、基本版（01_setup_guide_ja.pdf、3_ai_batch.gs、4_daily_report.gs）
に加えて、以下の3本の「そのまま動く」Google Apps Scriptが追加されています。
それぞれ自己完結しており、別々のGoogle Apps Scriptプロジェクトに1本ずつ
貼り付けて使います（基本版のスクリプトとは独立して動きます）。

共通の準備：どのスクリプトも Google アカウントと OpenAI の API キー
（従量課金。gpt-4o-mini なら非常に安価）だけが必要です。追加サービスの
契約は不要です。すべて「AIは下書き・文章だけ」「送信・確定は人間」の
設計にしてあり、自動送信は一切しません。

-----------------------------------------------------
① 6_gmail_inquiry_autoreply.gs — Gmail問い合わせの自動仕分け＆下書き返信
-----------------------------------------------------
何をするか：
  Gmailの特定ラベル（例：「問い合わせ」）が付いた未読スレッドをAIが読み、
  「緊急度・カテゴリ」を判定し、丁寧な返信の下書きを作ります。

導入手順：
  1. Gmail側で、対応したいメールに付くラベルを1つ用意する
  2. script.google.com で新規プロジェクトを作り、このファイルの中身だけを貼る
  3. ファイル先頭の CONFIG を自社向けに設定（ラベル名・署名・返信方針）
  4. 一度 手動で processInquiries を実行して動作確認（初回は権限承認が必要）
  5. 左メニュー「トリガー」→時間主導型→1時間おき などに processInquiries を設定

注意：下書きを作るだけです。送信は必ず人間が内容を確認してから行ってください。

-----------------------------------------------------
② 7_invoice_pdf_ai_email.gs — 請求書PDF自動作成＋AI添え状メール下書き
-----------------------------------------------------
何をするか：
  スプレッドシートの1行（請求先・件名・明細）から、消費税込みの請求書PDFを
  自動生成してGoogleドライブに保存し、AIが書いた添え状つきのGmail下書きを
  作ります。

導入手順：
  1. スプレッドシートに「invoices」という名前のシートを作る
     列：A請求先会社／B宛名／Cメール／D件名／E明細(品目;数量;単価を改行区切り)／F状態
  2. 「拡張機能」→「Apps Script」に、このファイルの中身だけを貼る
  3. ファイル先頭の CONFIG を自社向けに設定（自社名・登録番号・振込先など）
  4. 一度 手動で buildInvoices を実行して動作確認（初回は権限承認が必要）

注意：金額・消費税・合計はすべてコードで計算します（AIには添え状の文章だけ
書かせています）。金額をAIに生成させないのが事故らせないコツです。

-----------------------------------------------------
③ 8_meeting_minutes_ai_summary.gs — 議事録AI自動要約＋自動メール
-----------------------------------------------------
何をするか：
  会議の文字起こしやメモをスプレッドシートの1行に貼るだけで、AIが
  「要点3つ／決定事項／TODO（担当者・期限）」に整形し、結果をシートに
  書き込んで、必要なら参加者へメール送信します。

導入手順：
  1. スプレッドシートに「議事録」という名前のシートを作る
     列：A生の文字起こし/メモ／B要約結果(AIが書く)／C送信先メール(空なら送信しない)
  2. 「拡張機能」→「Apps Script」に、このファイルの中身だけを貼る
  3. A列にメモ、C列に送信先を入れてから、メニュー「議事録AI」→
     「選択行を要約してメール送信」を実行（初回は権限承認が必要）

注意：「事実だけを使う」「不明な項目は未定と書く」を指示に入れてあるので、
担当者や期限が本文に無い項目をAIが勝手に作文することはありません。

共通のご注意
-----------------------------------------------------
・スクリプトはあなたのGoogleアカウント内で動きます。当方がデータを預かる
  ことはありません。
・APIの利用料はご利用者負担です（gpt-4o-miniは非常に安価。まず少額から）。
・収益・時短効果を保証するものではありません。効果は対象業務により変わります。
・基本版の01_setup_guide_ja.pdf（OpenAI APIキーの取得方法など）は
  このPRO版にも同梱されています。キー取得で迷ったらそちらもご参照ください。
