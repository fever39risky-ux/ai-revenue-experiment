AI業務自動化キット
導入手順書（日本語・完全版）

「毎回ChatGPTに貼る」作業を、そのまま動く Google Apps Script 2本で自動化する。
コードが書けなくても、コピー＆ペースト中心で導入できます。

このキットで手に入るもの

  • スクリプト①（3_ai_batch.gs） — スプレッドシートの1列を、AIで一括処理（整理・要約・分類・翻訳など）。100行でも実行はボタン1回。
  • スクリプト②（4_daily_report.gs） — 決まった集計や進捗を、毎朝自動でメール送信。
  • 実務プロンプト20本（2_prompt_library.csv） — Google Sheets / Notion に取り込み可。
  • 請求書テンプレート（5_invoice_template.csv）／ワークフロー集（PDF）。

1. 準備するもの（所要 約5分）

  • Google アカウント（Google スプレッドシートが使えればOK）
  • OpenAI アカウント（APIキー取得のため。取得手順は次章）
  • ※ ChatGPT や Claude の有料プランは不要です。スクリプトは OpenAI API を直接呼び出します。
スクリプトは「従量課金の OpenAI API キー」を使います。ChatGPT Plus（月額）とは別物です。少額から始められ、gpt-4o-mini なら1行あたりの費用はごくわずかです（費用はご利用者負担）。

2. ステップ1：OpenAI APIキーを取得する

  1. platform.openai.com にアクセスし、ログイン（またはアカウント作成）します。
  2. 右上のメニュー →「API keys」（または platform.openai.com/api-keys）を開きます。
  3. 「Create new secret key」をクリックし、名前を付けて作成します。
  4. 表示された sk- で始まるキーをその場でコピーします（再表示できません）。
  5. 「Billing（お支払い）」で支払い方法を登録し、少額（例：$5〜$10）をチャージします。未登録だと呼び出しがエラーになります。
APIキーはパスワードと同じです。他人に共有・公開しないでください（GitHub やチャットに貼らない）。万一漏れたら、同じ画面で「Revoke」して無効化し、作り直します。

3. ステップ2：スクリプト①を導入する（一括AI処理）

  1. 対象のスプレッドシートを開きます。
  2. 上部メニュー「拡張機能」→「Apps Script」を選びます。
  3. エディタが開いたら、既存のコードを消して、3_ai_batch.gs の中身をすべて貼り付けます。
  4. 上部の CONFIG ブロックの API_KEY を、自分の sk-... キーに書き換えます。
  5. フロッピーアイコンで保存します。
  6. スプレッドシートに戻ると、メニューに「AIツール」が増えています（出ない場合は再読み込み）。

設定は CONFIG ブロックだけ変更すれば動きます：

項目意味
API_KEYあなたの OpenAI APIキー
MODEL使うAIモデル。gpt-4o-mini（安価）／精度重視なら gpt-4o
INSTRUCTIONAIへの指示。{input} が各行のA列テキストに置き換わります
INPUT_COL / OUTPUT_COL入力列 / 出力列（1=A列, 2=B列 …）
START_ROW処理を始める行（1行目が見出しなら 2）
MAX_ROWS一度に処理する最大行数（暴走防止）

4. ステップ3：スクリプト①を使う

  1. A列に処理したいテキストを入れます（例：問い合わせ文、商品説明、英文など）。
  2. 「AIツール」→「A列をB列へ一括処理」をクリック。
  3. 初回は Google の権限承認画面が出ます。自分のアカウントで許可してください。
  4. 完了トーストが出たら、B列に結果が入っています。
まず数行で試すのがコツです。INSTRUCTION を用途に合わせて書き換えれば、分類・要約・翻訳・タグ付け・感情判定などに使えます。処理済みの行は自動でスキップされるので、再実行しても安全です。

5. ステップ4：スクリプト②を導入する（毎朝の自動メール）

  1. 同じ Apps Script プロジェクトに 4_daily_report.gs を追加で貼り付けます（＋ボタン →「スクリプト」）。
    ※ スクリプト②は①の askAI() 関数を使うため、必ず①と同じプロジェクトに置いてください。
  2. RCONFIG を設定します：SHEET_NAME（集計対象シート名）、DATE_COL（日付列）、MAIL_TO（送信先）など。
  3. 一度手動で dailyReport を実行し、動作とメール受信を確認します（初回は権限承認あり）。
  4. 左メニュー「トリガー」→「トリガーを追加」→ 関数 dailyReport / イベントのソース「時間主導型」/「日タイマー」/「午前7〜8時」に設定します。
自動送信はまず自分宛だけでテストしてください。外部への誤送信に注意。

6. ステップ5：プロンプト集を取り込む

2_prompt_library.csv を Google Sheets で開く（ファイル →インポート）か、Notion のデータベースにインポートすれば、実務プロンプト20本をすぐ使えます。メール返信・議事録・データ整理・請求など、日々の作業をそのままコピペで進められます。

7. 困ったとき（トラブルシューティング）

症状対処
「AIツール」メニューが出ないスプレッドシートを再読み込み。それでも出なければ、コードが保存されているか確認。
セルに ERROR: ... と入る多くは APIキー未設定・請求未登録・キー誤り。CONFIG.API_KEY とOpenAIの Billing を確認。
401 / invalid api keyキーの貼り間違い・失効。OpenAIで新しいキーを作り直す。
429 / rate limit短時間に多すぎ。MAX_ROWS を小さくし、少し待って再実行（処理済みはスキップされます）。
insufficient_quota / 課金エラーOpenAIの Billing に残高が必要。少額をチャージ。
権限承認で止まる初回のみ Google の承認が必要。自分のアカウントで「許可」。

8. 安全と費用について（必ずお読みください）

  • 費用： スクリプトは従量課金の OpenAI API を使います。利用料はご利用者負担です（gpt-4o-mini は非常に安価ですが0円ではありません）。まず少額から。
  • データ： スクリプトはあなたの Google アカウント内で動きます。当方があなたのデータを預かることはありません。個人情報・機密は、社内規約を確認のうえ、必要ならダミー化してからお試しください。
  • APIキー： 他人に共有・公開しない。漏れたら即 Revoke。
  • 効果： 収益や時短効果を保証するものではありません。効果は対象業務により変わります。
  • 本商品： AIの助けを借りて制作したオリジナルの編集物です。転売・ドロップシッピングではありません。
