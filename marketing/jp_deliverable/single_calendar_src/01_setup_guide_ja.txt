Googleカレンダー → AI日報・週報の下書き【拡張版】 導入手順
============================================================

必要なもの：Googleアカウント、OpenAI の APIキー（従量課金。gpt-4o-mini なら
1日1回で1円未満が目安）。ChatGPT の有料プランは不要です。

【1】スプレッドシートを用意する
  新しいGoogleスプレッドシートを1つ作ります（名前は例：「日報AI」）。
  稼働ログと分類ルールはこのシートに保存されます。

【2】スクリプトを貼る
  シートの「拡張機能 → Apps Script」を開き、最初からあるコードを全部消して、
  calendar_ai_report_plus.gs の中身を丸ごと貼り付け → 保存。

【3】APIキーを登録する
  Apps Script 左の「プロジェクトの設定（歯車）」→「スクリプト プロパティ」→
  プロパティ OPENAI_API_KEY、値に sk- で始まるキーを追加。
  （キーをコードに直接書かないので、シートを共有してもキーは見えません）

【4】CONFIG を設定する（ファイル先頭）
  ・REPORT_TO：日報の宛先（下書きの宛先になるだけで送信はしません）／CC：必要なら
  ・CALENDAR_IDS：['primary'] は自分のカレンダー。チームの共有カレンダーも集計したい
    場合は、そのカレンダーの「設定と共有 → カレンダーの統合 → カレンダーID」を追加
    例：['primary', 'xxxx@group.calendar.google.com']
  ・EXCLUDE_WORDS：タイトルにこの語を含む予定は載せない（私用・休憩など）
  ・MAX_DESC_CHARS：予定の説明欄をAIに渡す文字数。0 にすると説明欄は一切送りません
  ・DAILY_HOUR：毎日何時台に作るか（初期値18）
  ・WEEKLY_REPORT：週の最終営業日に週報も作るなら true
  ・DRY_RUN：最初は true のまま（下書きを作らず、内容を実行ログに出します）

【5】初期設定
  関数選択で setupReport を選び「実行」。初回は権限の承認画面が出ます
  （「詳細」→「（プロジェクト名）に移動」→ 許可。自分で作ったスクリプトなので問題
  ありません）。次の3つが自動で用意されます：
    ・「分類ルール」シート（キーワード → 分類。上の行が優先）
    ・「稼働ログ」シート
    ・毎日 DAILY_HOUR 時台に動くトリガー1つ
  「分類ルール」を自分の顧客名・案件名に書き換えてください。例：
    キーワード「A社」→ 分類「A社案件」、「定例」→「社内会議」
  どのキーワードにも当たらない予定は「その他」になります。

【6】お試し
  シートを再読み込みすると上部にメニュー「日報AI」が出ます。
  ・「今日の日報を作る」→ Apps Script の「実行数」でログを開くと、下書きの本文が
    表示されます（DRY_RUN中）。稼働ログシートに今日の予定が入ります。
  ・中身に納得できたら DRY_RUN を false にして保存。以後は毎日、Gmailの下書きに
    「日報 yyyy/MM/dd」が入ります。開いて「所感」を書いて送るだけです。

【7】週報・月次集計
  ・週報：週の最終営業日（通常は金曜、金曜が祝日なら木曜）に「週報 yyyy/MM/dd週」
    の下書きが自動で作られます。メニュー「今週の週報を作る」でいつでも作れます。
  ・月次集計：メニュー「今月の分類別集計」「先月の分類別集計」で「月次集計」シートに
    分類ごとの時間(h)・件数・重複を除いた合計・稼働日数が書き出されます。
    顧客別の稼働時間の確認や、時間単価での請求の下書きに使えます。

時間の数え方
  ・重なった予定は二重に数えません（10:00-11:00 と 10:30-12:00 は合計2時間）。
  ・分類別の時間は分類ごとに重なりを除いて数えます。別の分類同士が重なっている場合、
    分類別の合計は「合計（重複を除く）」より大きくなることがあります。
  ・終日の予定は日報に名前だけ載せ、時間には数えません。
  ・日をまたぐ予定は、その日の23:59までを数えます。
  ・自分が「いいえ（辞退）」と回答した予定は数えません。

よくあるつまずき
  ・メニュー「日報AI」が出ない → シートを再読み込み。または onOpen を1回実行
  ・「カレンダーが見つかりません」→ CALENDAR_IDS のIDの誤り、または閲覧権限がない
  ・本文が「AI整形なし」になる → APIキーの誤り（ログに HTTP 401）。キーが無くても
    事実だけの日報は作られます
  ・下書きが増えない → 同じ件名の下書きが残っていると作り直しません（重複防止）。
    作り直したいときは古い下書きを削除してから実行
  ・祝日も作りたい → SKIP_HOLIDAYS を false に
  ・トリガーを重複して作った → setupReport をもう一度実行すると1つにまとまります

ご注意
  ・AIの文章は必ず目を通してから送ってください。事実にない成果を足さないよう指示
    していますが、表現の誤りはあり得ます。
  ・個人情報の伏せ字は代表的な書式（メール・電話番号・郵便番号）だけが対象です。
    氏名や住所などは説明欄に書かない、または MAX_DESC_CHARS を 0 にしてください。
  ・時短効果などを保証するものではありません。APIの利用料はご自身の負担です。
