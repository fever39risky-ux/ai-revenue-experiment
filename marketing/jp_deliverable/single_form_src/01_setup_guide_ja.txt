Googleフォーム問い合わせ AI仕分け＆担当者通知【拡張版】 導入手順
================================================================

必要なもの：Googleフォーム、Googleアカウント、OpenAI の APIキー（従量課金。
gpt-4o-mini は非常に安価）。ChatGPT の有料プランは不要です。

【1】回答シートを用意する
  フォームの「回答」タブ →「スプレッドシートにリンク」で回答シートを作ります。
  （フォームがまだ無く、先に試したいだけなら：新しいスプレッドシートのシート名を
  「フォームの回答 1」にして、02_sample_responses.csv を「ファイル → インポート →
  現在のシートを置換」で読み込めば、見本5件で【5】の一括仕分けを試せます）

【2】スクリプトを貼る
  回答シートの「拡張機能 → Apps Script」を開き、最初からあるコードを全部消して、
  form_ai_triage_plus.gs の中身を丸ごと貼り付け → 保存。

【3】CONFIG を設定する（ファイル先頭）
  ・API_KEY：OpenAI の APIキー（sk- で始まる文字列。他人に見せないでください）
  ・SHEET_NAME：回答シートのタブ名（初期値「フォームの回答 1」）
  ・BODY_FIELDS：本文にするフォームの質問タイトル。複数あれば ['ご用件', '詳細'] のように
  ・NAME_FIELD / EMAIL_FIELD：お名前・メールの質問タイトル（無ければ ''）
    EMAIL_FIELD を入れると、通知メールに「返信先＝お客様」が設定されます
  ・DEFAULT_TO：「その他」の送り先 / ESCALATION_TO：緊急度「高」の追加送り先
  ・CHAT_WEBHOOK_URL：Googleチャットにも流したい場合だけ（スペースの「アプリと統合 →
    Webhook」で作成したURL）
  ・DIGEST_TO：日次まとめの送り先 / REMIND_HOURS：何時間放置でリマインドするか
  ・DRY_RUN：最初は true のまま。

【4】初期設定
  上部の関数選択で setupTriage を選び「実行」。初回は権限の承認画面が出ます
  （「詳細」→「安全ではないページに移動」→ 許可。自分で作ったスクリプトなので
  問題ありません）。これで次の3つが自動で用意されます：
    ・「仕分け設定」シート（種別・通知先・AIへの説明）
    ・回答シート右端の5列（AI種別／AI緊急度／AI要約／対応状況／通知日時）
    ・トリガー3つ（フォーム送信時・1時間ごとのリマインド・毎朝8時台の日次まとめ）
  「仕分け設定」シートの通知先を自社のアドレスに書き換えてください。種別は行を足せば
  増やせます（例：「採用」「hr@…」「応募・求人の問い合わせ」）。C列の説明が具体的なほど
  AIの判定が安定します。通知先を空欄にした種別は、記録だけして通知しません。

【5】お試し
  ・testClassify を実行 → ログに {category: '不具合・クレーム', urgency: '高', …} が出ればOK
  ・フォームからテスト送信 → 回答シートの右端に判定が入り、実行ログに通知内容が出ます
    （トリガー実行のログは Apps Script 左の「実行数」で見られます）
  ・過去の回答がある場合は triageUnprocessedRows を実行（AI種別が空の行だけ処理します）

【6】本番化
  振り分けに納得できたら DRY_RUN を false にして保存。以降はフォーム送信のたびに
  担当者へ通知が届きます。対応を始めたら「対応状況」を「対応中」「完了」に変えてください。
  緊急度「高」が REMIND_HOURS 時間「未対応」のままだと、1回だけリマインドが届きます。

よくあるつまずき
  ・「回答シートが見つかりません」→ CONFIG.SHEET_NAME とタブ名を完全一致させる
  ・判定列が空のまま → BODY_FIELDS の質問タイトルがフォームと一字一句同じか確認
  ・AI要約が「（AI判定失敗: HTTP 401）」→ APIキーの誤り。429 は混雑（自動で再試行済み）
  ・メニュー「AI仕分け」が出ない → シートを再読み込み。または onOpen を1回実行
  ・トリガーを重複して作ってしまった → Apps Script 左の「トリガー」で余分なものを削除

ご注意
  ・AIの判定は間違えることがあります。通知メールには本文をそのまま付けているので、
    判断は必ず本文を見て人が行ってください。
  ・個人情報のマスクは代表的な書式（メール・電話番号・郵便番号）だけが対象です。
    住所や氏名など、本文中のそれ以外の情報はそのままAIに送られます。社内の規程に
    合わせて利用可否を判断してください。
  ・Gmail の1日の送信上限（無料アカウントで約100通）を超える量には向きません。
  ・時短効果などを保証するものではありません。APIの利用料はご自身の負担です。
