How it works

One row → one invoice

  • 1
    Type the client row
    Client, email, project, line items as Item ; Qty ; Price
  • 2
    Invoices → Create invoices
    Subtotal, tax & total calculated in code
  • 3
    PDF saved to Google Drive
    Auto-numbered INV-2026-0001, 0002…
  • 4
    Gmail draft with PDF attached
    You review, then press Send
  • 5
    Row marked Done + PDF link
    Re-run anytime; finished rows are skipped
