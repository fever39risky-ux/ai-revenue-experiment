## 事務でChatGPTを使うと、地味に困ること

メール返信、議事録の要約、問い合わせ対応、データの整理——このあたりはChatGPTがかなり速い。
でも事務で使い続けると、必ず一度はこれに刺さります。

**「書いていないことを、それっぽく埋めてくる」**

- 議事録にない「次回は来週金曜」を勝手に足す
- 問い合わせにない金額や日付を推測で書く
- 表に無い項目を「たぶんこう」で補完する

雑談ならご愛嬌ですが、**請求・日程・固有名詞・数字**が絡む事務では、この“それっぽい嘘”が一番こわい。
チェックに時間がかかって、結局あまり時短にならない、というのが「AIは事務に使えない」と感じる主因です。

これは**プロンプトの書き方**でかなり抑えられます。モデルを変えるより先に、指示の型を変えるほうが効きます。

## 解決策：「制約プロンプト」の4つの型

ポイントは、AIに**「埋めていい範囲」と「埋めてはいけない範囲」を先に宣言させる**こと。
次の4つを指示に足すだけです。

### 型1. 与えた情報だけを使わせる（推測の禁止）

```
以下の本文だけを根拠に回答してください。
本文に書かれていない事実・数字・日付・固有名詞は、絶対に補完しないでください。
情報が無い項目は「記載なし」と書いてください。
```

これ一行で「勝手に足す」が激減します。事務プロンプトの土台はこれ。

### 型2. 不確実なものにラベルを付けさせる

```
本文から確実に読み取れない箇所は、文末に [要確認] を付けてください。
```

消すのではなく**目印を付けさせる**のがコツ。人間の確認が「全文チェック」から「[要確認]だけ見る」に変わります。

### 型3. 出力フォーマットを固定して、検証しやすくする

```
次の形式で出力してください。
- 決定事項:
- ToDo（担当 / 期限）:
- 未確定・要確認:
```

形が決まっていると、抜けや捏造が**目視で一瞬**で分かります。自由記述より事故が減ります。

### 型4. 分からないときの逃げ道を用意する

```
判断できない場合は、無理に答えず「判断材料が不足しています。必要な情報：◯◯」と書いてください。
```

「分からない」と言っていい許可を与えると、AIは埋めるのをやめます。

## そのままコピペできる実務例3つ

### 例1. 議事録メモ → 決定事項・ToDo に整理

```
あなたは正確さ重視の事務アシスタントです。
以下のメモだけを根拠に整理してください。メモに無い事実は補完せず「記載なし」と書き、
確実に読み取れない箇所には [要確認] を付けてください。

出力形式：
- 決定事項:
- ToDo（担当 / 期限）:
- 未確定・要確認:

--- メモ ---
（ここに議事録メモを貼る）
```

### 例2. 問い合わせメールへの一次返信ドラフト

```
以下の問い合わせに対する一次返信の下書きを作ってください。
本文に無い金額・日付・約束は書かないでください。確認が必要な点は
「確認のうえ改めてご連絡します」に置き換えてください。
トーンは丁寧・簡潔。署名は入れないでください。

--- 問い合わせ ---
（ここに問い合わせ本文を貼る）
```

### 例3. バラバラな表記の正規化（表記ゆれ）

```
次のリストの表記を、指定ルールだけで統一してください。
リストに無い項目を足したり、順番を変えたりしないでください。
ルール：全角英数は半角に／会社名の後株・前株はそのまま維持／不明なものは [要確認]。

--- リスト ---
（ここに貼る）
```

## なぜ効くのか（ひとことで）

生成AIは「もっともらしく続きを書く」のが得意なので、**黙っていると空欄を埋めにいく**。
だから「埋めるな」「無い時はこう書け」「この形で出せ」と**先に制約を与える**と、埋める動機そのものを止められます。
プロンプトを長く凝るより、この4行を足すほうが事務では効きます。
